# devops-lifecycle-1
Description of Devops concepts, core principles and Life cycle stages.
DevOps is a software development methodology and cultural philosophy that combines software development (Dev) and IT operations (Ops) 
to shorten the systems development life cycle. 
It breaks down traditional silos to deliver applications and services at high velocity and high quality.
Core Principles of DevOps (CALMS Framework)The CALMS framework is the industry standard for summarizing the core pillars of DevOps:
Culture (Collaboration & Shared Responsibility): Shifts from siloed teams to a collaborative mindset where developers and operations 
share responsibility for the entire product lifecycle.Automation 
(Continuous Integration/Continuous Deployment - CI/CD): Uses automation to reduce manual, error-prone tasks (like testing and deployment) 
to speed up delivery.Lean (Flow & Waste Reduction): Applies lean principles to minimize bottlenecks, reduce unnecessary work (waste), 
and focus on efficiency.Measurement (Monitoring & Data-Driven Decisions): Uses metrics to track performance and gain insights into system health.Sharing
(Knowledge & Transparency): Promotes open communication and sharing knowledge, experiences, and tools across teams.Key DevOps Concepts for GitHubCI/CD Pipeline:
Automating building, testing, and deploying code changes securely.Infrastructure as Code (IaC): Managing infrastructure via configuration files and version control,
rather than manual setups.Monitoring and Logging: 
Actively gathering data to improve application performance.DevSecOps: Integrating security checks directly into the DevOps workflow.
Here are the stages of the Software Development Life Cycle (SDLC) explained:Planning: 
This foundational stage defines the project scope, goals, resources, and timeline, answering "what" is being built and why. 
It involves risk assessment, feasibility studies, and establishing a roadmap for development.Development (Coding): 
Developers translate design documents into functional software by writing code in appropriate programming languages. 
This is the most time-consuming phase where actual coding and unit testing occur.Building: This step involves compiling the source code into usable software artifacts, 
managing dependencies, and linking files to create a runnable application. 
It often acts as a bridge between coding and testing, ensuring the code is compiled correctly.
Testing: Quality assurance specialists identify and fix bugs to ensure the software functions correctly, meets requirements, and is reliable. 
It involves various checks, such as functional, performance, and security testing, before deployment.Release: 
The finished, tested application is packaged and prepared for release to the end-users, finalizing the development efforts. 
This stage often involves final stakeholder approval and packaging the product for production.Deployment: 
The product is officially moved into the production environment where users can access it, which may occur in stages or all at once. 
This involves installing the software on servers or distributing it to end-users.Operations: Once in production, 
the software requires ongoing support, maintenance, and periodic updates to ensure it functions effectively and securely. 
It focuses on maintaining the system to ensure long-term stability and usability.Monitoring: 
The team continuously tracks application performance, user feedback, and security in the live environment to catch issues early. 
This real-time visibility ensures rapid fixes for bugs or bottlenecks in the production system
